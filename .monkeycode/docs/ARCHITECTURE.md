# 高考志愿填报指导系统 - 系统架构

## 1. 系统架构概述

本系统采用前后端分离架构，支持Web和微信小程序双端接入。后端采用Go微服务架构，数据层基于Elasticsearch构建RAG知识库，AI能力对接国产大模型API。

## 3. 模块设计

### 3.1 用户服务模块 (user-service)

**职责**：处理用户注册、登录、信息管理

**核心接口**：
- POST /api/v1/user/register - 用户注册
- POST /api/v1/user/login - 用户登录
- GET /api/v1/user/profile - 获取用户信息
- PUT /api/v1/user/profile - 更新用户信息
- PUT /api/v1/user/preferences - 更新考生偏好

**数据模型**：
```go
type User struct {
    ID           uint64    `json:"id"`
    Username     string    `json:"username"`
    PasswordHash string    `json:"-"`
    Phone        string    `json:"phone"`
    UserType     string    `json:"user_type"`  // student/parent
    CreatedAt    time.Time `json:"created_at"`
}

type StudentProfile struct {
    UserID           uint64   `json:"user_id"`
    Province         string   `json:"province"`         // 河南省
    GaokaoYear       int      `json:"gaokao_year"`      // 2025
    Score            int      `json:"score"`            // 高考分数
    Rank             int      `json:"rank"`             // 省内位次
    PreferredSubjects []string `json:"subjects"`        // 偏好学科
    PreferredRegions []string `json:"regions"`          // 偏好地区
    InterestTags     []string `json:"interest_tags"`    // 兴趣标签
}
```

### 3.2 问答服务模块 (qa-service)

**职责**：处理AI问答、RAG检索、志愿推荐

**核心接口**：
- POST /api/v1/qa/chat - 发送问答消息
- GET /api/v1/qa/history - 获取对话历史
- POST /api/v1/qa/recommend - 获取志愿推荐
- GET /api/v1/qa/colleges - 获取推荐院校
- GET /api/v1/qa/majors - 获取推荐专业

**RAG检索流程**：
```
用户问题 → 向量化 → Elasticsearch检索 → 上下文组装 → 大模型生成 → 返回答案
```

### 3.3 数据服务模块 (data-service)

**职责**：高校/专业/分数线数据查询

**核心接口**：
- GET /api/v1/colleges - 高校列表查询
- GET /api/v1/colleges/:id - 高校详情
- GET /api/v1/colleges/:id/majors - 高校专业列表
- GET /api/v1/majors - 专业列表查询
- GET /api/v1/majors/:id - 专业详情
- GET /api/v1/scores - 录取分数线查询
- GET /api/v1/rankings - 排名查询

### 3.4 数据采集模块 (collector)

**职责**：从网络采集高校招生数据

**采集数据源**：
| 数据源 | 类型 | 说明 |
|-------|------|------|
| 高校官网 | 院校信息、专业设置 | 各高校招生网 |
| 阳光高考平台 | 招生计划、分数线 | 教育部官方平台 |
| 中国教育在线 | 院校排名、专业排名 | 教育资讯网站 |
| 河南省教育考试院 | 录取数据、分段表 | 省级官方平台 |

**采集任务**：
- 高校基础信息：学校名称、地区、类型、主管部门
- 专业设置：专业名称、学科门类、学位类型、学制
- 录取分数：文理科、各批次分数线、位次信息
- 排名数据：综合排名、专业排名、学科评估

## 5. RAG知识库设计

### 5.1 知识库内容

| 知识类型 | 内容描述 | 更新频率 |
|---------|---------|---------|
| 高校知识库 | 学校概况、历史沿革、师资力量、学科优势、招生政策 | 每年更新 |
| 专业知识库 | 专业介绍、培养方案、课程设置、就业方向 | 每年更新 |
| 录取知识库 | 历年录取分数、录取位次、录取规则、批次设置 | 每年更新 |
| 报考知识库 | 志愿填报技巧、冲稳保策略、专业选择方法 | 实时更新 |
| 规划知识库 | 职业规划建议、专业发展前景、行业分析 | 季度更新 |

### 5.2 RAG检索策略

**检索流程**：
1. **问题理解**：解析考生问题，提取关键信息（分数、偏好等）
2. **向量化检索**：将问题转换为向量，在ES中进行相似度检索
3. **混合检索**：结合关键词检索和向量检索，提高召回率
4. **重排序**：使用交叉编码器对检索结果进行重排序
5. **上下文组装**：将Top-K相关文档组装为提示词上下文
6. **答案生成**：调用大模型API生成最终答案

**检索参数**：
- Top-K: 5-10
- 相似度阈值: 0.7
- 最大上下文长度: 4096 tokens
