# 高考志愿填报指导系统 - 项目概述

## 1. 项目背景与目标

### 1.1 项目背景

河南省作为全国高考大省，每年有超过百万考生参加高考。志愿填报是高考后最关键的环节，涉及全国数千所高校、数万个专业，以及复杂的录取规则。考生和家长往往缺乏全面的信息渠道和专业指导，难以做出最优选择。

### 1.2 核心目标

为河南高考考生提供**智能化的志愿填报指导服务**，通过AI技术整合全国高校数据、专业排名、历年录取分数线等信息，结合考生自身情况，提供科学的报考建议和未来职业规划指导。

### 1.3 解决的问题

- 信息不对称：整合分散的高校招生信息，提供一站式查询
- 选择困难：基于考生分数和偏好，智能推荐合适的学校和专业
- 缺乏规划：提供未来职业发展建议，帮助考生做出长远规划
- 录取风险：提供录取概率分析，降低志愿填报风险

## 2. 目标用户

| 用户群体 | 需求描述 |
|---------|---------|
| 河南高三考生 | 查询高校信息、了解专业详情、获取志愿推荐 |
| 考生家长 | 了解录取规则、辅助孩子决策、查看院校对比 |
| 应届考生家长 | 提前了解志愿填报流程、准备报考策略 |

## 3. 核心功能模块

### 3.1 数据采集与RAG知识库

- **高校数据采集**：全国本科高校基本信息（学校概况、专业设置、师资力量等）
- **专业数据采集**：各高校开设专业、培养方案、就业情况
- **排名数据采集**：学校综合排名、专业排名、学科评估结果
- **录取数据采集**：各高校各专业在河南的录取分数线、录取名次段
- **RAG知识库构建**：将采集数据进行向量化存储，支持语义检索

### 3.2 智能问答系统

- **考生信息收集**：收集考生分数、位次、偏好专业、兴趣方向等
- **院校信息查询**：支持按分数、位次、地区、专业等条件筛选高校
- **专业信息查询**：查询专业详情、培养方向、就业前景
- **录取概率分析**：基于历史数据评估录取可能性
- **AI智能问答**：根据考生情况提供个性化建议

### 3.3 志愿推荐系统

- **分数匹配推荐**：根据考生分数和位次推荐合适的学校和专业
- **冲稳保策略**：提供冲、稳、保三个层次的志愿方案
- **专业优先级排序**：帮助考生合理排序志愿
- **录取风险预警**：提示各志愿的录取风险等级

### 3.4 信息查询与展示

- **学校排名查询**：查看各高校综合排名和专业排名
- **分数线查询**：查询各高校各专业历年录取分数线
- **专业对比**：对比不同学校相同专业的实力和录取情况
- **录取趋势分析**：展示某高校或专业的录取趋势变化

## 4. 项目交付形态

| 终端 | 说明 |
|-----|------|
| Web网站 | 完整的系统功能，支持复杂查询和分析 |
| 微信小程序 | 便捷的移动端访问，方便考生和家长随时查询 |

## 5. 项目约束与假设

### 5.1 技术约束

- 后端采用Go语言开发，保证高性能和并发处理能力
- 前端采用Vue.js框架，支持Web和小程序双端
- 数据存储使用Elasticsearch，支持全文检索和向量检索
- AI能力对接国产大模型API（如文心一言、通义千问等）

### 5.2 数据约束

- 数据主要来源于公开的网络数据（高校官网、教育部网站、阳光高考平台等）
- 需要定期更新数据，保持信息的时效性
- RAG知识库需要定期增量更新

### 5.3 用户约束

- 系统需要账号系统来保存考生个人信息和偏好
- 用户需同意数据使用协议用于个性化推荐
